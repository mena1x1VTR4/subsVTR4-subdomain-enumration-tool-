# subsVTR4-subdomain-enumration-tool-
A lightweight subdomain enumeration tool built using Python for target recon, created as a hands-on cybersecurity project. 👇
-----------------------------------------------------------------------------------------------------------------------------
 Hello everyone! I would like to introduce myself as a beginner in both cybersecurity and sharing my small projects on GitHub.

While watching the first part of a subdomain enumeration session, I saw the fast and powerful tools that most people use today for website recon. The idea came to my mind to build my own custom subdomain enumeration tool so I could gain hands-on experience and avoid being a script kiddie.
To be completely honest, the core logic and idea of this tool came from me, but I used AI to improve it and structure it better, as working with Python libraries is still new to me.

I would really appreciate it if you could share any tips or ideas to help me keep learning. Thanks!

## 👾Prerequisites & Installation
<>Make sure you have Python 3 installed, then install the required libraries: (<  pyfiglet , sys , requests , rich , socket  >)


## 🚀 How to Run

*Download both sub.py and menasubs.txt into the same folder. (or cd to the both tool and wordlist file and run it if linux)

*Open CMD (or Terminal) inside that folder.

*Run the script passing your target domain:

## 🤖 Windows

```cmd
python sub.py target.com
```
## 🤖 linux 
```cmd
python3 sub.py target.com

```
